# HR-System — Go-Live Runbook

> Запуск hr-system в прод. Архитектура: **один РФ-VPS + Docker Compose** (Postgres 18 + backend Bun/Hono + web + Caddy для TLS/реверс-прокси). Всё в РФ → 152-ФЗ ok. Идём по шагам; что я (Claude) не могу — помечено 🔒 (аккаунты/оплата/ключи делает Роман).

## Карта шагов

1. **🔒 Провижининг РФ-VPS** — создать сервер, получить IP + SSH.
2. **🔒 Домен + DNS** — направить домен на IP сервера.
3. **Установка окружения** — Docker + Compose + Caddy на сервере (скрипт, я дам команды).
4. **🔒 Сбор боевых секретов** — HH OAuth, LLM-ключ, SMTP, Telegram bot, генерация JWT/encryption-ключей.
5. **Прод деплой-конфиг** — Copilot готовит `docker-compose.prod.yml`, `Caddyfile`, `.env.prod`-шаблон, deploy-скрипт (отдельный issue).
6. **Деплой** — клон репо на сервер, сборка, миграции, seed owner.
7. **Включение флагов по одному + smoke-тест** каждого контура.
8. **🔒 Подключение HH + первая вакансия** — OAuth-коннект, опубликовать вакансию, расшарить careers-ссылку.
9. **Бэкапы + мониторинг** — daily pg_dump, healthcheck, логи.

## Шаг 1 — Провижининг РФ-VPS 🔒

**Цель:** один облачный сервер в РФ, к которому я (через тебя) подключусь и разверну систему.

**Провайдер (рекомендация):** Timeweb Cloud (`timeweb.cloud`) — простой, дешёвый, ДЦ в РФ. Альтернативы: Selectel, Yandex Cloud (Compute). Если у тебя уже есть РФ-хостинг — используй его.

**Что создать:**
- **Cloud Server (VPS)**, ОС **Ubuntu 24.04 LTS**.
- Конфигурация: **2 vCPU / 4 GB RAM / 80 GB NVMe** (хватит на старт: Postgres + backend + web). Можно 2GB для самого старта, но 4GB комфортнее.
- **Регион: Россия** (Москва или СПб).
- Публичный IPv4 — включить (нужен для домена и вебхуков).
- **SSH-ключ**: при создании добавить твой публичный SSH-ключ (если нет — сгенерировать: `ssh-keygen -t ed25519`, добавить `~/.ssh/id_ed25519.pub`).

**Что вернуть мне:**
- Публичный **IP сервера**.
- Подтверждение, что заходишь по SSH: `ssh root@IP` (или твой юзер) пускает.

**Стоимость ориентир:** ~400–700 ₽/мес за такой VPS на Timeweb/Selectel.

> Я не могу создать аккаунт и оплатить — это твой шаг. Как будет IP + SSH-доступ — дам Шаг 2 (домен/DNS) и Шаг 3 (установка Docker одной командой).
