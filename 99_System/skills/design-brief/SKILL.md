# Skill: design-brief

> Генерирует структурированный бриф для дизайнера логотипа. Используется перед передачей задания фрилансеру.
>
> **Триггер**: "Сделай бриф для дизайнера", "нужен бриф на логотип", "Skill: design-brief".
> **Модель**: Sonnet (средняя сложность, структурированный вывод).

## Входные данные (спросить у Романа если не указано)

1. **Бренд**: Pacific Star / SpecTechMash / оба?
2. **Задание**: с нуля / доработка черновика?
3. **Ключевые слова бренда**: 3-5 прилагательных, которые описывают образ
4. **Чего точно НЕ должно быть**: цвета, стили, ассоциации — табу
5. **Примеры которые нравятся**: 2-3 логотипа конкурентов или других брендов (необязательно)

## Алгоритм

### Шаг 1 — Собрать контекст из vault
Прочитать:
- `04_Brand/Pacific_Star.md` или `04_Brand/SpecTechMash.md`
- `04_Brand/Sites_Audit_2026-04-29.md` (цветовая палитра, текущий логотип)
- `04_Brand/Design_Role.md` (требования к формату)
- `99_System/Assistant_Brief.md` (бизнес-контекст)

### Шаг 2 — Сгенерировать бриф

Структура брифа:

```markdown
# Бриф на логотип — [Название бренда]

## 1. О компании (2-3 предложения)
## 2. Целевая аудитория
## 3. Позиционирование (чем отличаемся)
## 4. Что должен передавать логотип (3-5 характеристик)
## 5. Что точно НЕ должен передавать (табу)
## 6. Текущие активы (цвета, шрифты если есть)
## 7. Примеры для вдохновения (ссылки или описания)
## 8. Технические требования (форматы, размеры, требования Роспатента)
## 9. Дедлайн и этапы согласования
## 10. Контакт для сдачи
```

### Шаг 3 — Вывод

Бриф пишется в `90_Inbox/_AI_staging/design_brief_[бренд]_[дата].md`.

После подтверждения Романа — переносится в `04_Brand/Design_Briefs/`.

## Правила

- Не выдумывать характеристики бренда — только из vault и ответов Романа
- Технические требования Роспатента фиксированы (из `Design_Role.md`) — не менять
- Бриф должен быть таким, что дизайнер может работать БЕЗ звонка с Романом

## Вызов

```
Skill: design-brief
```
