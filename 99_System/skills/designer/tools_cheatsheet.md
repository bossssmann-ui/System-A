# Tools Cheatsheet — бесплатный стек для designer-skill

> На этой странице — все инструменты, которыми designer-агент имеет право оперировать. Никаких подписок, никакого Adobe / Sketch / Figma Pro / Midjourney. Если задача не покрывается этим списком — задача не для designer-skill.

## AI-генерация изображений

- **Recraft.ai** (recraft.ai). Идеально для → логотипов в векторе, иконок, иллюстраций, баннеров. Умеет генерить SVG, держит стиль, есть «brand» режим. Лимит → ~50 кредитов/день на free tier. Доступ из РФ → есть, без VPN. **Дефолт для генерации векторной графики.**

## Растровый редактор

- **Photopea** (photopea.com). Идеально для → пост-обработки сгенерированного, фотомонтажа, ретуши, сборки макета по слоям. Полноценный аналог Photoshop в браузере. Лимит → бесконечно, реклама сбоку. Доступ из РФ → прямой. **Дефолт для растровой постобработки.**

## Макеты и шаблоны

- **Canva free** (canva.com). Идеально для → быстрых соцсетевых постов, обложек, простых баннеров по шаблонам. Лимит → большинство шаблонов бесплатны, часть с пометкой Pro. Доступ из РФ → нестабильный, нужен VPN. **Использовать когда нужна скорость и есть VPN.**
- **Figma free** (figma.com). Идеально для → макетов сайта, длинных композиций, командной правки. Лимит → 3 файла на бесплатном тарифе, остальное платное. Доступ из РФ → нестабильный, нужен VPN. **Использовать для веб-макетов и UI.**

## Иконки и графика

- **Lucide Icons** (lucide.dev). Идеально для → outline-иконок 2 px stroke, единый стиль. Лимит → нет, MIT лицензия. Доступ → прямой. **Дефолт по иконкам для обоих брендов.**
- **Tabler Icons** (tabler.io/icons). Идеально для → запасной набор outline-иконок, если в Lucide нужного нет. Лицензия MIT. Доступ → прямой.

## Утилиты

- **Remove.bg** (remove.bg). Идеально для → быстро вырезать фон из фото техники для кейс-карточек. Лимит → 1 файл/день в HD бесплатно, превью без ограничения. Доступ → прямой.
- **Coolors** (coolors.co). Идеально для → проверить контраст палитры, подобрать гармоничные оттенки внутри уже утверждённой палитры. Лимит → бесплатно. Доступ → прямой.
- **Squoosh** (squoosh.app). Идеально для → пережать PNG/JPG/WebP для email и сайта без потери качества. Лимит → нет. Доступ → прямой.
- **TinyPNG** (tinypng.com). Альтернатива Squoosh для batch-сжатия. Доступ → прямой.

## Шрифты

- **Google Fonts** (fonts.google.com). Manrope, Inter, всё что использует бренд. Лимит → нет. Доступ → прямой.

## Правило выбора инструмента (для агента)

1. Нужна **векторная генерация** (лого, иконка, иллюстрация) → **Recraft.ai**.
2. Нужна **сборка макета** из готовых элементов (баннер, кейс-карточка, пост) → **Photopea** или **Canva** (если есть VPN).
3. Нужен **веб-макет / UI** → **Figma**.
4. Нужна **иконка** → **Lucide** (или Tabler если в Lucide пусто).
5. Нужна **фотообработка** → **Photopea** + **Remove.bg** + **Squoosh**.

Если инструмент требует VPN, отметить в плане реализации: «доступ через VPN».
