# Brand Quickref — выжимка для designer-skill

> Эту страницу designer-агент читает перед каждым визуалом. Источник правды — `04_Brand/Pacific_Star_Brand_System.md` и `04_Brand/SpecTechMash.md`. Сюда — только то, что нужно одним глазом.

## Pacific Star (ООО Компания «Тихоокеанская Звезда»)

### Палитра

| Роль | Имя | HEX |
|---|---|---|
| Primary | Pacific Deep (морской синий) | `#002B5C` |
| Accent | Star Gold (звёздное золото) | `#E8B647` |
| Background | White | `#FFFFFF` |
| Background alt | Off-white | `#F8FAFB` |
| Text main | Charcoal | `#1A1A1A` |
| Text secondary | Slate | `#5A6A7A` |
| Border | Cloud | `#E8EEF2` |
| Success | Green | `#2E7D32` |
| Error | Red | `#C0392B` |

Правило: Star Gold ≤ 10% площади. Pacific Deep — основной фон для hero и шапок. Никаких других синих/золотых оттенков.

### Типографика

- Заголовки: **Manrope** (Google Fonts, кириллица). H1 36–48 px / 700, H2 28–32 px / 600.
- Текст: **Inter** (Google Fonts, кириллица). Body 16 px / 400, line-height 1.55.
- Fallback (Word, email): Arial Black для заголовков, Arial для текста.

### Голос

B2B, спокойный, фактологический. Конкретика и цифры вместо эпитетов. Активный залог. Короткие предложения (≤18–20 слов). Без «лидеров рынка», «индивидуального подхода», «надёжного партнёра». Подробно — `04_Brand/Pacific_Star_Brand_System.md#voice--tone`.

## SpecTechMash (ИП Хмелев)

- **Палитра**: TBD (снять с сайта в репо `Auto`, см. `04_Brand/SpecTechMash.md`). Пока — используем нейтральную: чёрный `#1A1A1A` + белый + один акцент (оранжевый/жёлтый — уточнить у Романа).
- **Типографика**: TBD. Дефолт — те же Manrope/Inter, пока не появится своя.
- **Голос**: короткий, торговый, по делу. «Привозим. Растамаживаем. Доставляем.» Без обещаний типа «лучшая цена». Латиница в названии — финал (29.04.26).

## Иконография (оба бренда)

- Стиль: outline, 2 px stroke, скруглённые углы.
- Источник: **Lucide Icons** или Phosphor (бесплатные).
- Не смешивать стили иконок в одном носителе.

## Сетка и спейсинг

- Базовая единица — 8 px. Отступы кратны 8 (8, 16, 24, 32, 48, 64).
- Радиус скругления: 4 px мелкие, 8 px карточки, 16 px большие блоки.

## ⛔ Что НЕ делать

- Не использовать эмоджи в email-подписях и деловых материалах (исключение — ✅ для подтверждений в чатах).
- Не растягивать и не наклонять логотипы, не менять цвета вне палитры.
- Не вставлять стоковые фото техники — только реальные фото своего парка или клиентов.
- Не смешивать бренды Pacific Star и SpecTechMash в одном носителе.
- Не использовать латиницу «Pacific Star» в публичной сфере без русского названия рядом (53-ФЗ).
- Не предлагать рекламные штампы («лидер», «инновационный», «качественные услуги»).
