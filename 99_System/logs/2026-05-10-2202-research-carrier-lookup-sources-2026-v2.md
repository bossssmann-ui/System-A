# Ключевые факты

*   **ЕГРЮЛ (egrul.nalog.ru):**
    *   **Доступно публичным API:** ФНС предоставляет ограниченный API для получения выписок из ЕГРЮЛ/ЕГРИП, но обычно он требует регистрации и имеет лимиты на запросы. В публичном доступе на сайте egrul.nalog.ru можно получить одноразовую выписку по ИНН/ОГРН/названию в формате PDF. (Источник: egrul.nalog.ru)
    *   **Только парсингом:** Детальный сбор данных по большому количеству ИНН, автоматическая обработка PDF-выписок, извлечение специфических полей из HTML-представления на сайте. (Источник: Внутренние знания)
    *   **Лимиты:** На сайте - ручной ввод CAPTCHA для каждой выписки. Для API - могут быть суточные/месячные лимиты запросов, зависит от условий регистрации. (Источник: Внутренние знания, возможно устарело)
    *   **Антиботные защиты:** Google reCAPTCHA или аналогичная система на публичном сайте, возможно, проверка User-Agent и IP на уровне API. (Источник: Внутренние знания)
    *   **Типичные сложности парсинга:** Обновление CAPTCHA-системы, изменение структуры HTML/CSS страниц, необходимость OCR для PDF-выписок (если не используются готовые данные), медленная скорость загрузки страниц. (Источник: Внутренние знания)

*   **ФНС Прозрачный бизнес (pb.nalog.ru):**
    *   **Доступно публичным API:** Нет прямого публичного API для массового доступа, аналогично egrul.nalog.ru. Основной доступ через веб-интерфейс. (Источник: Внутренние знания, возможно устарело)
    *   **Только парсингом:** Сбор информации о налоговых задолженностях, сведениях о среднесписочной численности, уплаченных налогах, наличии лицензий и т.д., представленных на веб-страницах. (Источник: Внутренние знания)
    *   **Лимиты:** Ограничения по количеству запросов в единицу времени с одного IP, может требовать CAPTCHA. (Источник: Внутренние знания)
    *   **Антиботные защиты:** CAPTCHA, проверка User-Agent, возможный временный бан IP при интенсивных запросах. (Источник: Внутренние знания)
    *   **Типичные сложности парсинга:** Сложная структура HTML, динамическая подгрузка данных (AJAX), регулярные изменения дизайна, CAPTCHA. (Источник: Внутренние знания)

*   **ФССП (fssp.gov.ru):**
    *   **Доступно публичным API:** Предоставляет API для поиска исполнительных производств, но для его использования обычно требуется заключение соглашения или регистрация. Есть форма поиска на сайте. (Источник: Внутренние знания, возможно устарело)
    *   **Только парсингом:** Автоматизированный сбор данных о долгах физических и юридических лиц через веб-интерфейс, обработка результатов поиска. (Источник: Внутренние знания)
    *   **Лимиты:** На сайте - CAPTCHA для каждого запроса или серии запросов. API имеет свои лимиты, которые оговариваются при подключении. (Источник: Внутренние знания, возможно устарело)
    *   **Антиботные защиты:** CAPTCHA (включая сложные графические или текстовые), проверка User-Agent, IP-блокировки. (Источник: Внутренние знания)
    *   **Типичные сложности парсинга:** Частая смена CAPTCHA, редизайн страницы с формой поиска и результатами, защита от автоматических запросов на уровне сервера. (Источник: Внутренние знания)

*   **Картотека арбитражных дел (kad.arbitr.ru):**

    *   **Лимиты:** Ограничение на количество запросов в единицу времени, временные блокировки IP при высокой активности. (Источник: Внутренние знания)
    *   **Антиботные защиты:** Проверка User-Agent, поведенческий анализ (скорость запросов), временные блокировки IP. (Источник: Внутренние знания)
    *   **Типичные сложности парсинга:** Сложная структура DOM-дерева, AJAX-запросы для подгрузки данных, изменения в верстке, защита от DDoS-атак. (Источник: Внутренние знания)

# Распространенные заблуждения

1.  **"Все государственные данные доступны через простой публичный API":** **Спорно.** Многие государственные ресурсы предоставляют API, но часто они требуют регистрации, имеют жесткие лимиты, платны для коммерческого использования или предназначены для ограниченного круга пользователей (например, других госорганов). Массовый и свободный доступ через API крайне редок. (Источник: Внутренние знания)
2.  **"Парсинг государственных сайтов — это всегда законно и просто":** **Спорно.** Законность парсинга может быть спорной, особенно если это нарушает условия пользовательского соглашения сайта или создает чрезмерную нагрузку на сервер. Простота парсинга сильно преувеличена из-за антиботных систем и частых изменений в структуре сайтов. (Источник: Внутренние знания)
3.  **"Бесплатные государственные источники могут полностью заменить платные агрегаторы":** **Спорно.** Бесплатные источники предоставляют базовую информацию, но сбор, агрегация, анализ и предоставление данных в удобном виде (с выявлением связей, рисков) — это основная ценность платных агрегаторов, которую сложно воспроизвести вручную или простым парсингом. (Источник: Внутренние знания)
4.  **"Все данные о перевозчиках можно найти в одном государственном реестре":** **Спорно.** Информация о перевозчиках разрознена по множеству реестров: ЕГРЮЛ (юрлицо), ФНС (налоги), ФССП (долги), Ространснадзор (лицензии, проверки), арбитражные суды. Нет единого универсального государственного реестра, который охватывал бы все аспекты деятельности автоперевозчика. (Источник: Внутренние знания)
