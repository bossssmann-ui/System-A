# 99_System/logs/ — логи вызовов внешних воркеров

> Сюда падает каждый вызов Gemini CLI (и любого другого внешнего воркера, если появятся).
> Назначение: метрика качества (% «с первого раза»), разбор провалов, материал для еженедельного ретро.

## Соглашение по именам

`YYYY-MM-DD-HHMM-<worker>-<slug>.md`

Примеры:
- `2026-05-08-1430-gemini-research-multiagent.md`
- `2026-05-08-1502-gemini-writer-dispatcher-onboarding.md`
- `2026-05-08-1715-gemini-critic-tender-parser-tz.md`

## Шаблон файла

См. полный формат в [[Gemini_CLI_Setup#Формат-лога-вызова-Gemini]]. Минимум — фронтматтер с `verdict` и сырьё промпта/ответа.

## Что делать с этой папкой

- Не трогать руками — пишет Opus при каждом делегировании.
- Раз в неделю Opus делает self-review: считает долю `verdict: ok`, разбирает `verdict: needs-rework` и `failed`, корректирует промпты или правила маршрутизации.
- Старше 60 дней — архивировать в `90_Archive/logs/<YYYY-MM>/` (не делать сейчас, по факту накопления).
