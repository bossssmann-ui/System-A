## Что делать со списком (для Ирины)

1. Прочитать колонку "Действие" — там пометки от Claude (дубли, ошибки классификации, гос.орган).
2. По каждой строке без явного "удалить" — найти контакт (телефон диспетчера / email) через ЕГРЮЛ-сервисы (rusprofile.ru, kontur.focus) или прямой звонок по телефону из карточки 1С.
3. Пригласить в TG-группу Pacific Star — стандартное сообщение по [[20_SOP|SOP]] (если есть; иначе — попросить шаблон у Романа).
4. Отметить статус в этой таблице: "приглашён ✉️" / "вступил ✅" / "отказ ❌" / "не отвечает ⏳".

## Что Claude видит как риски этого списка

- 23 строки — **очень мало** для модели массового охвата. Реальный пул TG-группы должен быть в районе 100-500 контактов.
- Это только те, кого пользователь уже видел в 1С (т.е. кто хоть раз получал оплату). Новые перевозчики набираются через **другие каналы**: ATI.SU, биржи грузов, рекомендации. 1С-выгрузка — стартовый набор, не финальный пул.
- Дублирование (СибРокет ×2), ошибочные записи (Ространснадзор), пустые адреса (~10 строк без юр.адреса) — норма для 1С, но требует ручной чистки.
