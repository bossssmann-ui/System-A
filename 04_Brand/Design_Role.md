# Дизайн-исполнитель — роль в системе

> Один человек, две задачи с дедлайном. Всё остальное — вторично.
>
> Не нанимать агентство, не искать "дизайнера на всё". Нужен конкретный исполнитель под конкретный результат.

## Что нужно сделать (и только это)

### Задание 1 — Логотип SpecTechMash (с нуля)
- **Что есть**: только favicon. Нет ни концепции, ни фирменного стиля.
- **Что нужно**: финальный логотип — словесный знак + графический символ.
- **Формат на выходе**: SVG (масштабируемый), PNG 300 dpi на белом фоне (для Роспатента), PNG на прозрачном фоне (для сайта).
- **Ограничения**: только латиница или транслитерация допустима в логотипе (53-ФЗ — на вывесках нужен русский дубль, но в логотипе как ТЗ — допустимо).
- **Срок**: до конца мая 2026.

### Задание 2 — Финализация логотипа Pacific Star
- **Что есть**: черновик в `pacificstar.ru/_repos` (4 SVG-варианта), сделан Copilot. Цвета: `#0d2b5e` (тёмно-синий) + `#f5a623` (оранжевый). Шрифт: Inter.
- **Что нужно**: профессиональная доводка черновика. Не переделывать — довести до уровня, подходящего для подачи в Роспатент.
- **Формат на выходе**: те же форматы что для SpecTechMash.
- **Срок**: до конца мая 2026.

## Что дизайнер НЕ делает (сейчас)

- Баннеры VK / обложки TG → Маргарита (когда заполнит анкету)
- Шаблоны для соцсетей → после логотипов
- Редизайн сайтов → отдельно, не дизайнер
- Печатная продукция (визитки, бланки) → после регистрации ТЗ

## Как встроить в систему

```
Роман принимает решение "нанимаем дизайнера"
          ↓
Claude генерирует Design Brief (Skill: design-brief)
          ↓
Роман передаёт бриф дизайнеру
          ↓
Дизайнер сдаёт 2-3 концепта
          ↓
Роман выбирает → дизайнер доводит до финала
          ↓
Финал фиксируется в vault (04_Brand/) + идёт в Роспатент
```

## Где искать исполнителя

- Kwork.ru — раздел "Разработка логотипа", бюджет 3000–10000 ₽ за задание
- Fl.ru — можно найти с опытом в промышленном/транспортном секторе
- Telegram-каналы дизайнеров ДВ (если важна региональная специфика)
- Через Маргариту — если в анкете подтвердит навык Illustrator/Figma

## Критерии приёмки

- [ ] Логотип читается на белом и тёмном фоне
- [ ] Есть вариант для малых размеров (favicon 16×16)
- [ ] SVG без растровых включений (чистый вектор)
- [ ] PNG для Роспатента: 8-bit, минимум 400×400 px, белый фон
- [ ] Шрифты "вшиты" в SVG (converted to paths)
- [ ] Нет элементов, которые являются чужими ТЗ (проверить на схожесть)
