## Единый визуал подписи

### Принципы (одинаковые для обоих брендов, но цвета и логотип разные)

1. **Структура (сверху вниз)**:
   - Имя + Фамилия (жирно)
   - Должность (обычным)
   - Компания (полное юр.название курсивом)
   - Разделитель
   - Телефон рабочий (с международным форматом +7)
   - Email (кликабельный)
   - Сайт (кликабельный)
   - Адрес офиса
   - Логотип справа или слева

2. **Формат**: HTML с встроенным base64-логотипом (отображается в большинстве клиентов) + текстовый fallback в `text/plain` версии письма.

3. **Шрифт**: безопасный системный (Inter для онлайн-чтения, fallback на Arial / sans-serif для совместимости).

4. **Размер изображения логотипа**: высота 60px, ширина пропорционально (из SVG конвертим в PNG @2x для retina).

5. **Цветовые акценты в подписи**:
   - Pacific Star: имя — `#0d2b5e` (тёмно-синий), линия-разделитель — `#f5a623` (оранжевый акцент).
   - SpecTechMash: имя — чёрный `#0a0a0a`, линия-разделитель — серый `#1a1a1a`.

## Что нужно для финализации (в следующую сессию)

1. Собрать у Романа реальные данные по сотрудникам:
   - ФИО Татьяны (диспетчер).
   - ФИО логистов Москвы (Лог1, Лог2).
   - ФИО РОПа.
   - ФИО Хмелева (для подписей SpecTechMash).
   - Должности (как ровно официально называются).
   - Прямые рабочие телефоны (если есть).

2. Уточнить домен SpecTechMash.

3. Получить финализированный логотип SpecTechMash (сейчас только favicon).

4. Сгенерировать PNG-версии логотипов Pacific Star из SVG @2x для retina.

5. Свёрстать HTML-шаблоны для каждой роли (один шаблон, разные подстановки имени/должности/email/телефона).

6. Дать инструкцию каждому сотруднику как поставить подпись в свой почтовый клиент.
