# 04_Import — Импорт (СпецТехМаш)

> Модель D: импорт авто, мото и спецтехники из Японии, Ю.Кореи, Китая под заказ.
> Отдельный бренд — **СпецТехМаш**.

## Что хранится здесь

- Карточки активных заказов (клиент → что хочет → источник → этапы → статус)
- База поставщиков / площадок (Япония, Корея, Китай)
- Шаблон расчёта стоимости сделки
- Таможенные схемы и типовые документы
- База клиентов по импорту (отдельно от Модели A/B)
- Журнал закрытых сделок (уроки, маржа)

## Структура папок (создавать по мере роста)

```
04_Import/
  Clients/       — карточки клиентов импорта
  Deals/         — активные и закрытые сделки
  Suppliers/     — поставщики и площадки
  Templates/     — шаблон расчёта, типовые договоры
```

## Заполнить в первую очередь

- [ ] Шаблон расчёта импортной сделки (стоимость авто + доставка + таможня + комиссия)
- [ ] Список активных заказов на текущий момент
- [ ] Список ключевых площадок (Япония / Корея / Китай)

## Связь с другими контурами

- Крупные импортные заказы могут быть частью Модели C (см. `01_Operations/Models_Map.md`)
- Клиент может начать с импорта и перейти на грузоперевозки — флаг уровня в карточке
