# Шаблон проекта Модели C

> Каркас для большого грузового проекта Pacific Star (ООО Тихоокеанская Звезда) или ИП Хмелев. Цель: переложить методику Романа из головы в чеклист, чтобы каждый раз работа шла по одному маршруту, а позже можно было передать часть проектов старшему логисту или партнёру.
>
> **Как пользоваться:** на каждый реальный проект Модели C — копируем этот файл в `01_Operations/Model_C_Projects/<Название_проекта>/Project.md` и заполняем по разделам. Завершённые проекты остаются в архиве — там же.
>
> Версия шаблона: 1.0 (3 мая 2026).

---

## 1. Когда это Модель C — чеклист квалификации

Лид становится Моделью C, если хотя бы 2-3 признака из списка:

- [ ] Стоимость проекта от 1 млн ₽ или сложная конфигурация платежей.
- [ ] Несколько отправок в рамках одного проекта (не разовый рейс).
- [ ] Комбинация ресурсов: свой парк + наёмные + спецтехника / импорт / перевалка.
- [ ] Длительность исполнения от 2 недель.
- [ ] Требуется коммерческое предложение перед договором (не работает по типовой ставке).
- [ ] Тендер / конкурс / сложные согласования с госорганами.
- [ ] Нужны нестандартные документы (банковская гарантия, договор поручения, страхование грузов с особыми условиями).
- [ ] Высокая маржа — обычно 15-30% против 5-10% у Моделей A/B.
- [ ] Клиент новый, без истории работы — нужна тщательная проверка.

Если 2-3 галочки → **переходим в этот шаблон**, ставим owner = Роман, отделяем от обычной воронки в Lead_Pipeline (помечаем `L-C-NN`).

Если 0-1 — это **не Модель C**, оформляем как обычный лид B / A+ / A.

## 6. Этапы проекта (Stage Map)

| Этап | Что делается | Кто | SLA / срок | Документы | Чеклист |
|---|---|---|---|---|---|
| **1. Квалификация** | Оценить, реально ли это Модель C. Проверить клиента (ИНН, история, репутация). Понять реальный масштаб и срочность. | Роман | 1-2 дня от первого контакта | — | См. раздел 1 |
| **2. Коммерческое предложение** | Расчёт груз.плана, формирование цены и условий. Подготовка КП. | Роман + бухгалтер | 3-5 дней | КП в pdf/docx | Раздел 4-5 заполнен |
| **3. Переговоры** | Согласование цены, условий, сроков. Возможно тендер. | Роман | 1-3 недели | Протокол согласований | Раздел 8 балансных точек |
| **4. Договор** | Рамочный договор + спецификации. Подписание. Возможно банковская гарантия. | Роман + бухгалтер + юрист | 1 неделя | Договор, спецификации, гарантии | Все документы подписаны обеими сторонами |
| **5. Исполнение** | Управление каждой партией: подбор транспорта, погрузка, контроль, разгрузка, документы. | Татьяна / Ирина / Роман | По графику проекта | Поручения экспедитору, расписки, ТТН, ТН, путевые | Каждая партия = отдельный лид в Lead_Pipeline с пометкой `L-C-NN-партия-X` |
| **6. Финансовое закрытие** | Сверка с клиентом, формирование УПД на каждую партию или сводно, получение оплаты. | Бухгалтер + Роман | По договорным срокам | УПД, акт сверки | Все УПД подписаны, оплата получена |
| **7. Закрытие проекта** | Сводный отчёт. Уроки. Архивация. | Роман | 1 день после получения последней оплаты | Отчёт по проекту | Раздел 14 заполнен |

## 7. Документы проекта

### Юридические
- [ ] Рамочный договор (транспортной экспедиции или перевозки в зависимости от роли).
- [ ] Спецификация № 1, 2, 3 ... к договору на каждую партию.
- [ ] Дополнительные соглашения (если меняются условия).
- [ ] Протокол согласования разногласий (если был).
- [ ] Банковская гарантия / страхование ответственности (если требуется тендером).

### Под каждую партию
- [ ] Поручение экспедитору (если экспедитор) — на партию или на отдельный рейс.
- [ ] Экспедиторская расписка (приёмка + выдача).
- [ ] Складская расписка (если есть промежуточное хранение).
- [ ] Транспортная накладная.
- [ ] ТТН (если применимо).
- [ ] Путевой лист (если Модель A).
- [ ] Договор субподряда с конкретным перевозчиком (если наёмный).

### Финансовые
- [ ] Счета на каждую партию или сводно.
- [ ] УПД (бухгалтер, по дню закрытия каждой партии).
- [ ] Отчёт экспедитора (если требует клиент).
- [ ] Акт сверки.

### Коммерческие / тендерные
- [ ] Коммерческое предложение.
- [ ] Презентация компании (если запросят).
- [ ] Документы по аккредитации у клиента (если есть).
