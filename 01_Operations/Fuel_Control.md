## Сверка ежемесячно (по данным УЛ и топливных карт)

### Процесс

1. В конце каждого месяца (5-го числа) выгружаешь из УЛ:
   - По каждой машине: сумму пробегов по закрытым рейсам (км).
   - Период: с 1-го по последний день месяца.

2. По топливной карте смотришь:
   - Сумма выданного дизеля за тот же период (л).
   - Контактируешь поставщика, если нет данных → запрашиваешь отчёт.

3. Вычисляешь:
   - Фактический расход = литры с карты (минус остаток в баках на конец месяца, если меняется + остаток на начало).
   - Ожидаемый расход = пробег × норма / 100.
   - Отклонение = (фактический − ожидаемый) / ожидаемый × 100%.

4. Если отклонение **> +20%**:
   - Звонок водителю: "На что ушёл дополнительный расход?"
   - Проверяешь путевые листы за месяц: нет ли неучтённых рейсов, есть ли холостые пробеги.
   - Если причина не ясна → звонок Роману.

5. Результат документируешь в ежемесячном отчёте.

## Обнаружение аномалий в процессе (по ГЛОНАСС)

Если у машин установлен ГЛОНАСС (уточнить у Романа):

- Система может показывать расход в реальном времени по двигателю.
- При резком отклонении (утечка, слив) → появляется график аномальный.
- Диспетчер видит в УЛ или отдельном приложении → звонок водителю: "Проверь люк, заливную горловину."

**Если ГЛОНАСС нет:** полагаешься только на ежемесячный анализ.

## Вложенные расходы по топливу

Если в рейсе учитывается авансовая выдача топлива водителю (например, для рейса за Хабаровск > 500 км), он покупает сам и потом отчитывается:

- Водитель приносит чеки → Татьяна суммирует и вычитает из зарплаты при расчёте маржи.
- Или: Роман выдаёт наличные авансом → водитель затем отчитывается.

**Порядок:** уточнить с Романом в День 1. Какой механизм используется в Pacific Star?

## Что делает Татьяна

1. **Ежемесячно (5-е число):** выгружает пробеги по машинам из УЛ за прошлый месяц.
2. **Запрашивает у поставщика топлива:** отчёт о выданных литрах за месяц.
3. **Вычисляет фактический и ожидаемый расход**, сравнивает.
4. **При отклонении > +20%:** звонит водителю с расспросом, проверяет путевые листы.
5. **Составляет ежемесячный отчёт** и отправляет Роману с выводами.
6. **Ведёт архив отчётов** (папка `01_Operations/Fuel_Reports/` или в УЛ).

---

## Что делает Роман

1. **День 1:** подтверждает нормы расхода по машинам (техпаспорт или опыт).
2. **День 1:** предоставляет контакты поставщика топлива и лимиты по картам.
3. **Ежемесячно:** получает отчёт от Татьяны, анализирует отклонения.
4. **При аномалиях:** обсуждает с водителем / проверяет машину механически (утечки, неисправности).
5. **Ежемесячно:** передаёт бухгалтеру данные расхода для калькуляции себестоимости рейсов.

## План наполнения и первые шаги

**День 1 (1 мая):**
- Роман называет нормы расхода для каждой машины → заполняются в таблице "Норма расхода".
- Роман показывает договор с поставщиком топлива → контакты и лимиты.
- Уточняется: есть ли ГЛОНАСС, как вводить данные расхода в УЛ.

**Неделя 1 (5 мая):**
- Первое заполнение рейсов в УЛ с пробегами → тестирование.
- Проверка, как выглядит выгрузка пробегов из УЛ (возможно, нужна инструкция от разработчика УЛ).

**Месяц 1 (5-31 мая):**
- Накопление данных по рейсам.
- **5 июня:** первый ежемесячный отчёт за май.
