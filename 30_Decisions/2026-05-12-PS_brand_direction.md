# Решение: Бренд-направление Pacific Star — «Печать Меридиана» (направление D)

## Контекст

До 12.05.2026 у Pacific Star был только черновой логотип от Perplexity + GitHub Copilot (звезда + надпись), не утверждённый. Палитра-черновик — navy `#002B5C` + gold `#E8B647` — при ресёрче была признана слишком близкой к FESCO/DHL/DPD дженерик-эстетике. Шрифты Manrope + Inter — нейтральные, без характера.

Роман прямо озвучил требования к новому бренду: «концептуально, строго как в бизнесе, пунктуально, мощно, свежо, сильно, стильно». И: «не должны быть похожими и одинаковыми как все ИИ-разработки в дизайне» — нужна «человеческая рука».

12.05.2026 проведена глубокая бренд-проработка через designer-агента + ресёрч-агента (см. `04_Brand/Brand_Concepts_PS_2026-05-12.md` — 3 направления с полным описанием). Роман выбрал направление D «Печать Меридиана» с двумя итерациями по геометрии знака.

## Решение

С 12.05.2026 утверждается **бренд-направление D «Печать Меридиана»** для Pacific Star.

**Большая идея:** бренд = оттиск, печать, штамп. Растёт из портовой и таможенной культуры ДВ (на каждом контейнере штамп) и из реальной операционки бизнеса (поручения экспедитора, расписки, складские расписки по ФЗ-140). Это поднимает физический документарный характер бизнеса до уровня айдентики.

**Система знаков — два регистра:**

- **Полная печать** (`04_Brand/Logo_Pacific_Star_Seal_Full.svg`): круглая печать с надписью по верхней дуге «ТИХООКЕАНСКАЯ ЗВЕЗДА», по нижней — «ЭКСПЕДИЦИЯ · ПЕРЕВОЗКИ · С 2008». В центре — шестилучевая метка ориентирования. Применяется в документах, КП, договорах, hero сайта, нижнем колонтитуле. Минимум — 56 px.
- **Упрощённая метка** (`04_Brand/Logo_Pacific_Star_Mark.svg`): только центральная шестилучевая метка в кольце, без круговых надписей. Применяется в favicon, аватарах, малых UI. Минимум — 16 px.

**Геометрия меток зафиксирована Романом 12.05.2026:**

- Внешний круг печати r=92, stroke 2.5pt; внутреннее кольцо r=82, stroke 0.5pt.
- Точки-разделители по бокам печати — (14,100) и (186,100), r=1.8.
- Текст верхней дуги — Inter Display Bold 10pt, letter-spacing 3.
- Текст нижней дуги — Inter Display SemiBold 8pt, letter-spacing 2.
- Шестилучевая метка: прямые лучи длиной 58 (stroke 2pt), диагональные длиной 31√2 ≈ 44 (stroke 1.4pt, на 25% короче прямых), центральная точка r=4.

**Новая палитра:**

| Цвет | HEX | Назначение |
|---|---|---|
| Stamp Ink | `#1F2A35` | Основной: логотип, заголовки, основной текст |
| Document | `#F2EDE3` | Фон бланка (не белый) |
| Customs Orange | `#B8531C` | Акцент: CTA, разделители, не более 10% площади |
| Steel | `#5C6470` | Вторичный текст, линии |
| Mist (опц.) | `#9CA8B5` | Линии сетки, второстепенные |
| White | `#FFFFFF` | Контраст в digital |

**Новая типографика:**

- Заголовки и wordmark — **Inter Display** (rsms/inter, OFL).
- Текст — **Golos Text** (Королькова, OFL) — изначально под государственную среду РФ, идеален для бланковой эстетики.
- Mono — **JetBrains Mono** (OFL) — метки, координаты, реквизиты.

## Триггеры пересмотра

- Знак не пройдёт экспертизу Роспатента по схожести с существующими ТЗ → итерация формы метки.
- Палитра не ляжет на ключевые носители (печать, ткань, мерч) → корректировка с типографом.
- Customs Orange в реальном применении окажется конфликтным с фотографиями техники/контейнеров → замена акцентного цвета.
- Inter Display + Golos Text не дадут нужной читаемости в КП на 14pt → пересмотр пары.
