# _AI_staging — Буфер предложений AI

> Всё, что AI предлагает изменить в vault, сначала появляется здесь.
> Ничего не применяется без явного подтверждения Романа.

## Принцип работы

1. AI делает анализ или предлагает изменения → пишет результат в этот folder
2. Роман проверяет файл → говорит "ок" / "не то" / "поправь"
3. Только после подтверждения: AI применяет изменения в основной vault
4. После применения: файл из staging удаляется или архивируется

## Формат файлов

- `inbox_review_YYYY-MM-DD.md` — результат weekly-inbox-review
- `suggestion_<тема>_YYYY-MM-DD.md` — разовые предложения по структуре / заметкам
- `draft_<название>.md` — черновики новых заметок перед добавлением в vault

## Что НЕ хранится здесь навсегда

Staging — это очередь, не архив. После применения или отклонения — файл уходит.
Если файл лежит > 7 дней без решения — значит, нужно его пересмотреть или удалить.
