# 03_Finance — Финансы

> Платежи, налоги, лизинги, учёт, передача бухгалтеру.
> Контур для Романа и бухгалтера (Екатерина / Евгения, аутсорс).

## Что хранится здесь

- Платёжный календарь (лизинги, аренды, налоги, сборы)
- Передача документов бухгалтеру: что отдали, за какой период
- Лизинговые договоры (ключевые параметры: ставка, дата окончания, ежемесячный платёж)
- Налоговые события и риски
- Касса / движение денег по месяцам (сводка)

## Что НЕ хранится здесь

- Первичка (накладные, акты, счета) — у бухгалтера
- Детальный учёт Умной Логистики — там же

## Заполнить в первую очередь

- [ ] Платёжный календарь по лизингам (3 тягача + 4 прицепа)
- [ ] Даты сдачи отчётности
- [ ] Структура расходов по Модели A (топливо, ТО, зарплаты, лизинги)

## Ритм

- Раз в месяц (или при изменениях): передача бухгалтеру → отметка в `Accounting_Handoff.md`
- Еженедельно: обновление платёжного календаря если были платежи
